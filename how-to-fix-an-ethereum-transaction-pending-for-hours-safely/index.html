How to fix an Ethereum transaction pending for hours safely

An Ethereum transaction pending for hours usually has a fee below the base fee or a stuck earlier nonce. Learn when to wait, speed up or cancel safely.

By Web3 Hub NewsroomNov 19, 2026 · 20:20 UTC3 min read

An Ethereum transaction usually stays pending for hours when its max fee is below the base fee or an earlier transaction from the same wallet has not confirmed.

The max fee or an earlier nonce can keep later transactions pending

A max fee set when network fees were lower can leave a transaction waiting. Under EIP-1559, a transaction can enter a block only when its max fee covers that block’s base fee; if the base fee stays higher, the transaction waits until it falls or you replace the transaction.

Open the transaction in MetaMask and compare its max fee with current fee estimates. You can wait for the base fee to drop, or speed up the transaction by replacing it with a higher fee using the same nonce. A replacement with a different nonce is a separate transaction.

A replacement can quietly fail when it raises only one fee setting. Nodes commonly require both the max fee and priority fee to rise by at least 10% over the pending transaction. Raise both by that amount or more, and confirm the replacement still uses the original nonce.

An earlier transaction from your wallet can block every later one. Ethereum confirms transactions from each wallet in nonce order, so a later transaction waits even if its fee is high. In Etherscan, compare the nonce on the pending transaction with the status of earlier transactions from the same address; resolve the earliest pending nonce first.

A private RPC can make a transaction hard to find on a public explorer. Flashbots is an Ethereum research and infrastructure organization; a private route such as Flashbots Protect can send a transaction outside the public mempool while it waits for a builder to include it. The background on searcher bundles explains how transactions can be assembled for block builders.

If the wallet shows pending but Etherscan does not, check whether you used a private RPC and ask your wallet or RPC provider how to track or replace that submission. Contact support if you cannot identify the pending nonce, or if a replacement using that nonce is still not visible after checking the route you sent it through.

Answers to common transaction questions

How do I find the nonce of my stuck transaction?

Open the transaction details in MetaMask or look up its hash on Etherscan. The nonce is shown in the transaction details; compare it with earlier transactions from the same wallet.

Does cancelling a transaction refund the gas?

A cancellation replaces the pending transaction using the same nonce. The original pending transaction has not used gas, but the cancellation replacement can incur a fee if it is included in a block.

How do I set a custom nonce in MetaMask?

Open MetaMask’s advanced settings and enable custom transaction nonces, then enter the nonce of the pending transaction when preparing its replacement. Check the nonce carefully: reusing it replaces the pending transaction, while a different nonce creates another transaction.
