How can you verify a chain ID before adding an EVM network?

To verify a chain ID before adding a network, compare the project’s official documentation with a trusted RPC response, then review the wallet prompt.

By Web3 Hub NewsroomNov 21, 2026 · 17:26 UTC2 min read

Before adding a network, compare its Chain ID in the project’s official documentation with the ID returned by a trusted RPC endpoint, then review the wallet’s network details before approving.

  • Find the Chain ID in the network project’s official documentation.
  • Ask a trusted RPC endpoint for its chain ID using JSON-RPC.
  • Compare the values and confirm the RPC endpoint in the wallet prompt.

A Chain ID identifies the network wallet software will use for transactions. Ethereum mainnet’s Chain ID is 1.

Chainlist presents network details together, making its wallet network-addition checks a practical example of comparing the details before approval. Use the project’s documentation to confirm that Chainlist’s listed RPC endpoint belongs to the network you intend to add.

Compare the documented Chain ID with the RPC response

Start with the network project’s official documentation, then query a trusted RPC endpoint listed or endorsed there. The JSON-RPC method eth_chainId returns the endpoint’s Chain ID as a hexadecimal quantity.

Compare the RPC response with the documented value, converting decimal to hexadecimal if needed. For Ethereum mainnet, Chainlist’s Chain ID of 1 should match 0x1 from eth_chainId.

A matching number alone does not authenticate a network: different networks can reuse the same Chain ID. Confirm the RPC endpoint’s address against the project’s documentation as well. A mismatch in either the ID or endpoint is a reason to stop and recheck the details before adding the network.

Review the wallet’s network details before approving

Say you want to add Ethereum mainnet. You find Chain ID 1 in the project’s documentation, confirm that a trusted mainnet RPC endpoint returns 0x1, and compare the wallet prompt with those details.

Read the Chain ID and RPC endpoint shown in the prompt before approving. The values should match the ones you verified; also review the displayed network name and native currency against the project’s documentation. A familiar name by itself is not enough to identify the network.

This process applies whenever you add an EVM network through a wallet or Web3 tool. Chainlist can help you locate the network’s listed Chain ID and RPC endpoint, while the project’s documentation and a trusted RPC response let you check that the details agree before you connect.
