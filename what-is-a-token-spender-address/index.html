What Is a Token Spender Address?

A token spender address is the contract you authorize to move approved tokens; learn how ERC-20 allowances, NFT operators and revokecash display it.

By Web3 Hub NewsroomNov 19, 2026 · 14:36 UTC3 min read

A spender address in a token approval is the contract or address you authorize to move tokens from your wallet, up to the approved amount. In revokecash, the spender column identifies that authorized address so you can judge whether you recognize it. For ERC-20 tokens, approve(spender, amount) records an allowance, and the spender can call transferFrom(from, to, amount) to use it.

An approval connects three things: you as the owner, the token, and the spender. The spender gets permission to move tokens within the allowance; the tokens stay in your wallet until a transfer happens.

How does a spender address work in a token approval?

A DEX swap often uses the exchange’s router contract as the spender. Say you approve a Uniswap router to spend a set amount of a token: during the swap, the router can pull the approved tokens from your wallet and route the trade.

Permit2 is another common spender that apps use to route approvals. Its name may appear in an approval record even when you started the action in a different app.

ERC-721 calls this role an operator. A setApprovalForAll approval lets that operator transfer every NFT from that collection in your wallet, so it covers the collection rather than a single NFT.

A familiar spender can still change if it is an upgradeable proxy. A proxy points to contract code that can be replaced; if that code changes, the same approved address may follow new behavior without you granting a new approval. When reviewing an approval, treat the address as the permission you granted, then consider whether the contract behind it can change. An approval record alone does not tell you whether its code is upgradeable.

In revokecash, compare the spender address with the app or contract you remember approving, and note the token and allowance beside it. Etherscan can help identify an address and inspect its contract, but a familiar name or label is a clue to verify, not proof that the approval is safe.

What should I know after finding a spender?

Can a spender take tokens I receive after approving?

Yes, if the allowance still covers them. An ERC-20 allowance sets the total amount the spender may transfer; transfers use up that allowance, but tokens you receive later can still be taken if enough allowance remains. An unlimited approval can therefore apply to tokens that arrive after you approved it.

Does revoking a spender cancel a pending transaction?

No, revoking an approval does not cancel a transaction already pending in your wallet. The revoke changes the allowance when it is confirmed on-chain; a pending spend transaction could execute first, depending on transaction order. Check the transaction status as well as the approval after submitting a revoke.
