How to Move Native USDC Between Chains With CCTP

How Circle CCTP moves native USDC between chains: it burns USDC on the source, then mints native USDC on the destination after Circle attests the burn.

By Web3 Hub NewsroomNov 18, 2026 · 08:11 UTC2 min read

Circle’s CCTP moves native USDC between chains by burning it on the source chain, attesting to that burn, then minting the same amount on the destination.

Take a transfer from Ethereum to Polygon PoS. The Polygon bridge provides background on moving supported assets between those chains; CCTP’s key distinction is that the USDC arriving on Polygon PoS is native USDC.

An Ethereum to Polygon PoS transfer

On Ethereum, the sender starts CCTP’s depositForBurn process to burn USDC. The burn destroys that USDC and emits a message naming Polygon PoS as the destination and specifying the recipient.

Circle’s attestation service waits for the Ethereum transaction to reach finality, then signs the message. That signed attestation is proof for the destination chain that the source-chain burn is final.

To complete the transfer, someone submits the signed message using receiveMessage on Polygon PoS. The destination contract mints the same amount of native USDC to the named recipient; submitting the mint transaction requires Polygon PoS gas.

That burn-and-mint flow works because Circle issues USDC on each supported chain. It retires the supply on Ethereum and issues it on Polygon PoS, rather than sending a wrapped version of USDC across.

Standard Transfer waits for source-chain finality. CCTP V2 Fast Transfer settles sooner for a fee.

A transfer that has burned USDC but has not yet minted it on Polygon PoS is not lost. The attestation remains retrievable from Circle’s API using the burn transaction hash, so the signed message can be retrieved and the mint submitted later.

Questions readers ask next

What happens if the destination mint transaction fails?

The USDC remains burned on Ethereum, but the transfer can still be completed. Retrieve the attestation from Circle’s API with the burn transaction hash, then submit the message to the destination contract again in a mint transaction.

Can CCTP move USDC.e?

CCTP’s burn-and-mint flow is for native USDC. USDC.e is a bridged token, so it is not the native USDC that CCTP burns on Ethereum and mints on Polygon PoS.
