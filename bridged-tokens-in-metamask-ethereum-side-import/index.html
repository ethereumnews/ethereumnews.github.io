Bridged tokens in MetaMask: Ethereum-side import

How to add a bridged token to MetaMask after a Gnosis Chain withdrawal: claim it on Ethereum, then import its verified Ethereum contract address.

By Web3 Hub NewsroomNov 17, 2026 · 12:37 UTC2 min read

Switch MetaMask to Ethereum after the Gnosis Chain withdrawal is validated and claimed, then import the token using its verified Ethereum contract address so MetaMask can display the balance held there.

Start with the withdrawal transaction hash and the Ethereum recipient account. Gnosis Bridge handles this route; the Gnosis Chain to Ethereum with Gnosis Bridge article covers the transfer, while the withdrawal still needs a claim on Ethereum before the returned balance is ready to display.

Claim the withdrawal before importing

A pending withdrawal is not yet an arriving Ethereum wallet balance. Open the withdrawal in the bridge explorer with its transaction hash, and confirm the Ethereum destination account and token after validation and claim.

This check ties the withdrawal to the wallet you intend to use in MetaMask. If the Ethereum destination differs from the selected MetaMask account, importing the token into that account will not display the withdrawal’s balance.

Import the Ethereum-side token address

Use the token’s Ethereum contract address because MetaMask needs the address for the network where the balance is held. A token representation on Gnosis Chain may use a different contract address from its Ethereum counterpart, so the Gnosis Chain address is not a substitute.

Switch MetaMask to Ethereum and open its option to import or add a custom token. Paste the verified Ethereum contract address, review the token details MetaMask displays, and import it.

For the address, use a trusted source that identifies the token on Ethereum, such as the token details linked from the withdrawal record or an Ethereum block explorer. GnosisScan can help identify a token on Gnosis Chain, but its address alone does not establish the contract address to use on Ethereum.

Importing adds the token to the Ethereum account’s asset list; it does not move funds or complete a bridge withdrawal. The balance belongs to the account that received the claimed withdrawal, so check that account’s token balance in an Ethereum explorer and confirm it matches the balance shown in MetaMask.
