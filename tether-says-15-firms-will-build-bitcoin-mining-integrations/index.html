Tether says 15 firms will build Bitcoin mining integrations

Tether says 15 mining operators, hardware makers and pools will build integrations for its open kit, aiming to let software work across mining systems.

By Web3 Hub NewsroomOct 25, 2026 · 08:09 UTC2 min read

Tether said on October 24 that 15 Bitcoin mining operators, ASIC manufacturers and mining pools have committed to building and maintaining integrations for its Mining Development Kit, an open-source framework intended to let software work across different mining systems. The company says the shared interface could reduce the need for developers to build separate integrations for each platform. Tether’s announcement names the participating companies.

Which mining companies have committed to MDK?

The participants include Bitdeer, BITMAIN, Canaan, Foundry Digital, Luxor Technology, MicroBT, F2Pool and OCEAN, according to Tether. The full list also includes ACME Swisstech, Elektron Energy, EMCD, Heatbit, Proto, SpiderPool and Stratum V2.

Tether says each participant will build and maintain an MDK Worker, a translation layer connecting its hardware, pool or system to the kit. The Worker maps a company’s existing interface to a shared format; participants choose which functions they expose, and do not need to replace their systems.

How would the shared interface help mining operators?

Mining sites can combine machines from different manufacturers, pools and management software, Tether said. Without a common interface, developers may need to create separate integrations for each environment, while operators manage systems independently.

Applications built for MDK could connect through the shared layer instead. Tether says this could let monitoring tools and AI agents work across more mining infrastructure without requiring a new integration for every vendor. Its QVAC mining agent is already operating on MDK, the company said, as an early example.

When is MDK’s stable release expected?

Tether said MDK is open source and available for developers to test and build on now. The company targeted the first stable 1.0 release by the end of 2026; that is the next stated milestone for the project.
