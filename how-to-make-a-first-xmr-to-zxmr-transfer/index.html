How to Make a First XMR-to-zXMR Transfer

ZeroFi’s XMR-to-zXMR flow sends Monero to a deposit address and mints a token on Ethereum Sepolia; check the network, minimum and confirmation status before starting.

By Web3 Hub NewsroomSep 30, 20262 min read

A first XMR-to-zXMR transfer sends Monero to a bridge deposit address and, after the required confirmations, mints a wrapped token on Ethereum Sepolia. ZeroFi’s interface currently lists a minimum deposit of 0.01 XMR and 10 source-chain confirmations; those figures can change, so check the live interface before sending.

The bridge turns an asset on Monero into a token that can be held on an Ethereum test network. For more on the design, see ZeroFi’s explanation of how its XMR bridge works. The trade-off is that zXMR can be used by Ethereum applications, while activity on Ethereum is public and does not inherit Monero’s transaction privacy.

What do you need before sending XMR?

You need a Monero wallet with spendable XMR and an Ethereum wallet connected to Sepolia. The Ethereum wallet receives zXMR and needs Sepolia ETH to pay transaction fees when interacting with the bridge or token. XMR pays its own Monero network fee when sent.

Check the network shown in the bridge before connecting. The current interface identifies the destination as Sepolia, a test network, while the source is Monero. That means the transfer is not a direct move of XMR onto Ethereum: the bridge receives XMR, and the destination wallet receives a separate Ethereum token.

How do you make the first XMR-to-zXMR transfer?

Choose XMR as the source and zXMR as the destination, connect the Ethereum wallet, and enter an amount at or above the displayed minimum. The interface should generate a Monero deposit address tied to the transfer; copy that address carefully into your Monero wallet and verify it before confirming the send.

  • Keep the bridge page open and confirm its network and destination wallet address.
  • Send only the amount you entered to the generated Monero address.
  • Wait for the bridge to register the deposit and meet the required confirmations.
  • Follow the interface’s prompt to complete the zXMR mint, then check the receiving wallet on Sepolia.

The interface lists 10 confirmations on the source chain, so a transaction may not appear immediately. A Monero transaction ID can help you check whether the send was broadcast; the bridge’s status is what indicates whether it has processed the deposit and enabled the next step.

What should you check if zXMR does not appear?

First compare the transaction amount, deposit address, source transaction status and connected Sepolia wallet with the details shown for the transfer. Confirm that the wallet is on Sepolia and that it can display the zXMR token; a missing token display does not by itself prove the bridge failed.

The live interface sets a 0.01 XMR minimum, so this is not a risk-free test with valueless test coins. Treat a bridge that connects Monero mainnet to Sepolia as an experimental route: only send what you can afford to lose, and do not repeat the transfer until the first one reaches a clear status. The next step is to check the interface’s confirmation requirement and transaction status before making any further deposit.
