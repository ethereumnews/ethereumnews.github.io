How to Clear a Pending Mantle Bridge Wallet Nonce

A stuck Mantle Bridge transaction usually needs a same-network replacement at the blocked nonce; clearing wallet activity alone does not cancel an on-chain transaction.

By Web3 Hub NewsroomOct 16, 2026 · 10:00 UTC3 min read

A pending nonce on the network where a Mantle Bridge transaction began can block later wallet transactions until it confirms or is replaced. A nonce is the account’s transaction counter on one network; it does not carry across Ethereum and Mantle. For route and settlement details, see this mantle bridge guide. The key first step is to check the transaction on that network’s block explorer.

Why is a Mantle Bridge transaction blocking my wallet?

Wallets send transactions from an account in nonce order, so a later transaction may wait behind an earlier one that has not been included. Check the explorer for the pending transaction and its nonce on the network where you approved the bridge deposit or withdrawal. If the transaction is confirmed or failed there, its nonce has been used; a wallet screen that still says “pending” may only be showing stale activity.

A bridge transfer also has more than one stage. If the source-chain transaction is confirmed, replacing it will not resolve a delayed destination step; check the bridge status and follow the applicable claim or message process instead. A pending wallet nonce matters when the source transaction itself remains unconfirmed.

How do I replace or cancel the pending transaction?

Use the wallet’s speed-up option to rebroadcast the same transaction with a higher fee, or replace it with a new transaction using the same nonce. A replacement can only compete with the pending transaction on that same network. To cancel a transfer, some wallets let you send a zero-value transaction to your own address with the blocked nonce; if it confirms first, the original bridge transaction cannot use that nonce.

  • Open the explorer for the correct network and locate the transaction by its hash.
  • Confirm its status and nonce before changing wallet settings.
  • Use the wallet’s speed-up or replacement flow, keeping the original nonce.
  • Wait for the replacement to confirm, then check the wallet and bridge status again.

The replacement must meet the network’s fee rules, which can vary with congestion and wallet settings. Check the displayed network and fee before signing: using a new nonce will not clear the earlier transaction, and a replacement that confirms may spend funds if it is a transfer rather than a cancellation.

Does clearing wallet activity clear the nonce?

No. Clearing or resetting a wallet’s local activity can remove a stale pending label, but it does not cancel a transaction already broadcast to the network. If the explorer shows no pending transaction, refreshing the wallet’s activity may fix the display; if the explorer still shows one, replace it on that network. Once the lowest pending nonce confirms or is replaced, later transactions can proceed in order.
