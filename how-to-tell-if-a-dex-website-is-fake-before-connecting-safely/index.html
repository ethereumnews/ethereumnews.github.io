How to tell if a DEX website is fake before connecting safely

To tell if a DEX website is fake before connecting a wallet, open the official domain, compare it character by character and inspect the first prompt.

By Web3 Hub NewsroomNov 19, 2026 · 08:24 UTC3 min read

Open a DEX website from its official documentation or social account, confirm the exact domain, then inspect the first wallet prompt before connecting. Phishing clones can copy a site’s appearance, but they must use different domains or contracts, so verify both before you approve anything.

SunSwap is a TRON DEX where users swap TRC-20 tokens through liquidity pools; a note on SunSwap TRC-20 swap mismatches covers what to do when a token mismatch appears. SUN.io publishes SunSwap’s official domain and contract addresses, so use those as your reference.

Use this checklist before connecting, and keep the official page open so you can compare the wallet request against what the site says it should do.

  • Official source link: Open the site from SUN.io’s official documentation or social accounts. Search ads can lead to phishing pages, so skip them.
  • Exact domain: Compare every character with the domain published by SUN.io. Look for swapped letters, extra words, or a different ending; a matching logo does not verify the address.
  • Bookmark: Save the confirmed page and use that bookmark next time. This reduces the chance of landing on a lookalike through a search result or message.
  • First prompt type: A normal wallet connection asks to connect. Connection alone grants no token access; an approval or signature can authorize an action, so an immediate approval or unexplained signature is a red flag. Reject it and leave the site.
  • Spender address match: When you later approve a token, compare the spender with the router address in the official documentation. Use its TRONSCAN contract page to confirm the address and check whether the contract is verified; verification shows source code and creator address, but does not by itself prove the site is genuine.

Read the wallet prompt before acting

Wallet prompts can appear in a sequence, so treat connection and token approval as separate decisions. After connecting, read each prompt before confirming: check what action it requests, which token is involved, and which spender would receive permission.

For a first approval, stop if the spender differs from the router address SUN.io publishes. Search that address on TRONSCAN and compare it with the official reference; a similar name or familiar page design is not a match.

A signature deserves the same pause. A prompt to sign immediately after connection is unexpected for a plain connect request. Decline it unless the official site clearly explains the action and you intended to take it.

What to do next

  • Open the DEX through its official source.
  • Compare and bookmark the exact domain.
  • Connect only after the first prompt says connect.
  • Before approving tokens, match the spender to the official router address on TRONSCAN.
