MetaMask Confirmation Screen: Bridge Fields to Check

What to check on a wallet confirmation screen before signing a bridge transaction: verify the network, contract, request, spending cap, amount and source-chain fee.

By Web3 Hub NewsroomNov 20, 2026 · 11:00 UTC3 min read

Check the network, contract, request type, spending cap, amount and fee before signing a bridge transaction. Use this list while the MetaMask confirmation popup is open; it is the last chance to catch a wrong chain, contract or allowance. The Berachain bridge moves assets between chains for use in Berachain’s DeFi ecosystem, so confirm the details match the transfer you intended.

  • Network: Confirm MetaMask shows the source chain you are bridging from, such as Ethereum. The network determines where the transaction is sent and which native token pays its fee.
  • Contract: Compare the interacting contract address in the popup with the Berachain bridge address in its official documentation. A familiar token name or website is not a substitute for matching the address.
  • Request type: Read whether MetaMask is asking for a token approval or a transfer. These are separate confirmations: an approval lets a contract use a token allowance; the transfer sends the assets. An ETH transfer may not need a token approval, while a USDC transfer may.
  • Spending cap: For an approval, set the cap to the amount you plan to bridge. MetaMask lets you edit the approval’s spending cap instead of accepting an unlimited allowance. For instance, if you intend to bridge 25 USDC, enter 25 USDC as the cap. That limits the permission to the intended amount rather than leaving a larger allowance available to the contract. MetaMask explains how to customize a cap in its spending cap instructions.
  • Amount and fee: Check the token and amount being transferred, then review the estimated network fee. The fee is paid in the source chain’s native token; for a transaction on Ethereum, that means ETH. Make sure the total matches what you expect to spend.

What should I do if the popup asks for an approval?

Set the spending cap to the transfer amount, then review the approval as its own transaction. The bridge may ask for the transfer in a second MetaMask confirmation after the approval is submitted; inspect that screen separately and check its network, contract, amount and fee again.

If an existing allowance looks larger than you intended, review it before proceeding. Etherscan’s Token Approval Checker can show token approvals for review and revocation. That check is useful for an allowance you granted earlier; it does not replace checking the current popup.

Before you sign, compare the displayed details with the transfer you planned. For an approval, set the cap to the exact amount you intend to bridge; that can spare you from granting a broader allowance by mistake.
