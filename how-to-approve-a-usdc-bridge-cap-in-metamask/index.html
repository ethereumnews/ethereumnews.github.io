How to Approve a USDC Bridge Cap in MetaMask

How to approve USDC spending for a bridge in MetaMask: verify the spender, set the cap to your transfer amount, pay gas, and confirm the allowance.

By Web3 Hub NewsroomNov 28, 2026 · 04:56 UTC2 min read

A USDC bridge spending approval in MetaMask is an ERC-20 approve transaction: verify the spender, choose a cap, and pay source-chain gas before the bridge can use that allowance.

Start with USDC and an amount entered in the bridge UI on the source chain. MetaMask must be set to that network, and your wallet needs USDC plus the network’s native gas token. A USDC bridge transfer moves USDC between chains; this approval lets its contract access the amount you authorize.

  1. Click Approve. The bridge UI requests permission, and MetaMask opens a spending-cap request. The bridge contract needs an allowance because ERC-20 transferFrom can move tokens only within the allowance set by approve(spender, amount), as defined by the EIP-20 Token Standard.
  2. Read the spender address in MetaMask. Compare it with the bridge contract address in the bridge’s documentation. The allowance goes to the address shown as the spender, regardless of which site opened the request. MetaMask Support describes this request as an editable spending cap.
  3. Edit the cap to the transfer amount. MetaMask lets you change the amount before approval. Choose the amount you intend to bridge instead of an unlimited cap. For USDC, a new approve amount overwrites the existing allowance, so you can change the cap directly; it is not added to the old cap.
  4. Confirm and wait for inclusion. Submit the approval in MetaMask and pay gas on the source chain. Once the transaction is included, the contract has an on-chain allowance up to the amount you chose. On Ethereum, native USDC also supports ERC-2612 permit, a signed approval that can avoid a separate gas-paid approval transaction; whether that route is available depends on the bridge’s request. EIP-2612 defines the permit mechanism.
  5. Submit the bridge transaction, then check the result. Return to the bridge UI and submit the transfer once its button is active. In Etherscan, open the approval transaction and confirm its Approval event shows the spender and cap you selected. That event and the active bridge button confirm the allowance step completed.

For comparison, USDT on Ethereum requires a nonzero allowance to be reset to zero before setting another nonzero amount. USDC’s overwrite behavior lets you set the new cap in the approval request itself. You can now proceed with the bridge transfer using the confirmed allowance you chose.
