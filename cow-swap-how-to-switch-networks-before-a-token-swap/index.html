CoW Swap: How to switch networks before a token swap

Learn how to switch wallet networks before swapping tokens: select the chain in CoW Swap, approve the wallet prompt, then confirm the network and balance.

By Web3 Hub NewsroomNov 27, 2026 · 00:08 UTC2 min read

CoW Swap lets you choose a network for a token trade and prepare a swap with your wallet on that chain. In cowswap, select the network where your tokens are held, then approve the wallet’s switch request; the app and wallet need to use the same chain for a regular swap. If no request appears, switch networks in the wallet and reconnect.

A chain ID is the numeric identifier for a network: Ethereum is 1, Gnosis Chain is 100, Arbitrum One is 42161 and Base is 8453. CoW Swap’s network selector makes checking a wallet’s chain ID a practical step before swapping, since the app’s selected network and the wallet’s active network should match.

How do you switch wallet networks before swapping tokens?

Start with a wallet installed in your browser or available through WalletConnect, and tokens on the network you intend to use. Choose that network in the app, then approve the switch in the wallet when its prompt appears.

  1. Open the network selector in cowswap and choose the chain that holds the tokens for your trade.
  2. When the wallet asks to switch networks, review the requested network and approve the change.
  3. If no prompt appears, open the wallet’s network selector and choose the same chain directly. Reconnect the wallet or refresh the app if needed.
  4. Confirm the app and wallet show the intended network, then check that the token balance is available before reviewing the swap.

Say your tokens are on Arbitrum One. Select Arbitrum One in the app and approve the wallet request; if the request does not appear, choose Arbitrum One in the wallet selector, then reconnect. The chain ID, 42161, can help distinguish it from Ethereum, Gnosis Chain or Base if you need to verify the active network.

Does switching networks move tokens between chains?

No. Switching changes which chain the wallet is connected to; it does not move tokens between chains. A token balance on Ethereum, for instance, will not become a balance on Arbitrum One just because the wallet network changes.

For a regular same-chain swap, select the network where the tokens already sit and make sure the app and wallet agree before choosing tokens. Once the network and balance match your plan, you can choose the tokens and review the quote.
